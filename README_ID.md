# Sistem Skill AI — Versi Awal

Paket ini berisi instruksi skill yang bisa digunakan ulang. Ini **bukan pemasangan otomatis** ke menu Skills ChatGPT.

## Isi
- `00_Pusat_Kendali`: memilih skill dan mengatur alur kerja.
- `01_Game_Studio`: game.
- `02_Website_Studio`: website.
- `03_App_Studio`: aplikasi.
- `04_Design_Studio`: desain.
- `05_Digital_Product_Studio`: produk digital.
- `06_QA_Fixer`: pemeriksaan dan perbaikan.
- `07_Deployment_Studio`: publikasi.

## Cara pakai paling sederhana
1. Buka file `SKILL.md` untuk tugas yang dibutuhkan.
2. Salin instruksinya ke percakapan atau lingkungan coding yang mendukung instruksi skill.
3. Tambahkan brief proyek di bawah instruksi.
4. Minta AI mengerjakan hasil nyata, bukan hanya menjelaskan langkah.

## Pembagian alat yang disarankan
- ChatGPT: merencanakan dan menyusun instruksi/kode.
- Codex: mengerjakan berkas kode jika aksesnya tersedia.
- Replit: alternatif jika lebih mudah untuk membuat dan menjalankan proyek.
- GitHub: menyimpan kode.
- Cloudflare: memublikasikan proyek yang kompatibel.

Tidak semua alat harus dipakai sekaligus. Mulai dari satu proyek kecil dan gunakan alat tambahan hanya jika diperlukan.
